Chat System MVP

{{.Title}}

聊天系統本體提供統一 API 與三種 Web 形態，不為任何單一外部系統另開專屬產品窗口。

Desktop 桌機全畫面

雙欄工作區，適合長時間處理多個對話與檔案操作。

 Mobile 手機全畫面

單欄切換流程，優先處理對話列表與訊息頁面切換。

 Embed 嵌入式浮動視窗

可插入其他系統頁面中的輕量聊天入口，適合客服與內嵌通知。

目前方向

  • 外部整合走統一 API 契約，不單獨為 ERP 開分類或專屬頁面
  • 桌機、手機、嵌入式三種形態共用同一套聊天能力與權限邏輯
  • 下一步聚焦聊天列表、訊息流、上傳與 embed token / session 邊界
